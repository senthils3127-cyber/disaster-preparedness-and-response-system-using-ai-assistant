# 🌍 Disaster Preparedness & Response System

A web-based platform designed to **inform, prepare, and assist communities during disasters**.  
It provides **real-time alerts, resources, volunteer registration, and an AI-powered emergency assistant** to help people stay safe.

---

## 🚀 Features

- **📊 Dashboard** – Displays active alerts, rescue teams, shelters, and system uptime.  
- **🚨 Disaster Alerts** – Generate and view simulated emergency alerts (Floods, Cyclones, Earthquakes, Heatwaves).  
- **📚 Resources** – Access guides for emergency kits, evacuation plans, and first aid.  
- **🤖 AI Emergency Assistant** – Ask questions about disasters and receive instant safety instructions.  
- **🆘 SOS Button** – Quick emergency activation alert.  
- **🌙 Dark Mode Toggle** – Switch between light and dark themes.  
- **👥 Volunteer Registration** – Register volunteers with skills (medical, rescue, fire, tech) and assign them to teams.  
- **📞 Emergency Contacts** – Quick access to police, ambulance, fire service, and emergency numbers.  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Design:** Responsive layout with modern UI (cards, grids, dark mode)  
- **Storage:** LocalStorage for volunteer registration data
